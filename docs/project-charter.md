## 已锁定基线
见 `AGENTS.md`「设计基线」表。要点：2D 俯视 / 改写因果系统（+主线任务+面板成长骨架）/ 三国·赤壁 / PC 优先 / 正剧+轻度元幽默+民间志怪奇幻 / 实时轻动作 ARPG / Godot 4.7.1 GDScript。

## 核心循环（Loop A · 任务→探索→改写→反馈）
1. **任务**：系统派"改写节点"主线任务（例：*赤壁·借东风——让诸葛亮借风失败*）。
2. **探索**：玩家在赤壁开放世界探索 / 战斗 / 结盟 / 收集（找风之后人、求术士、截气象线索）。
3. **改写**：满足条件触发关键抉择（杀 / 救 / 策反某历史人物）。
4. **反馈**：系统计算历史偏差值，发因果点 + 经验 + 解锁，播"历史线分叉"反馈。
5. **成长**：回面板升级 / 技能树 / 系统兑换，系统派下一节点。
