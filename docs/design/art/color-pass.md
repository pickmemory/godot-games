## 2. 分带规则（公式与阈值 · 代码锚点 `terrain.js · chunkColorBands`）

每 chunk **一次**产出 16×16 列级带索引 LUT（`world._generate` 缓存于 chunk 记录，mesher 查表 O(1)）——满足"禁止逐方块重采样噪声"的性能约束。

```
湿度 v    = simplex(seed+1201, wx·0.006, wz·0.006)·0.5+0.5 + (h−24)·0.03   → clamp 0..1
草带      = v < 0.40 ? 嫩绿 : v < 0.62 ? 黄绿 : 枯黄
树冠带 lv = simplex(seed+4501, wx·0.006, wz·0.006)·0.5+0.5 + (h−24)·0.02   → clamp 0..1
叶带      = lv < 0.45 ? 浓绿 : lv < 0.70 ? 黄绿 : 枯黄赭
```

- **频率 0.006** → 色带补丁约 80~160 格宽（截图级大色块，不是噪点）。
- **高度干燥偏置 `(h−24)·0.03`**：谷地更润（压向嫩绿）、山脊更枯（压向枯黄），与裸岩带互相呼应——玩家从颜色就能读出"那边地势高"。
- 现场分布（seed 1337，出生点 7×7 chunk 实测）：草带 45% / 33% / 22%，叶带 57% / 20% / 23%，裸岩+碎石 ~2.1%，沙 ~14.8%。
- 附带修正：树的地表判定改为"草皮即地表"（沙/裸岩列自动无树），原 `ground <= SAND_H+1` 早退条件删除。

**变体瓦片机制**（`textures.js · BAND_TILES`）：GRASS_TOP/GRASS_SIDE/LEAVES 的绘制器接受色调参数 `tint {grass|leaf, dirt?, mottle?}`；变体瓦片**追加**在既有瓦片之后（33~38 号），既有 TILE 序号与布局函数不动，草方块注册表仍指向基准瓦片——mesher 按 LUT 换变体。atlas 高度 9 行→10 行（64→80px），材质/渲染管线零改动。

## 3. 时段暖调（汉代绢画 · 代码锚点 `main.js · updateDayNight`）

1. **日落 `#ff9a5a → #e29a68`**：原值偏糖果橙；赭石琥珀降饱和、微收红，落在绢画矿物颜料（赭石/土黄）色域内。
2. **破晓新增停点 `#e8c79e`**：原破晓是深夜→白昼直线插值，中段路过死灰蓝；现改两段（深夜→绢赭→天蓝，55% 处过停点），卯时日出前后有"揭卷"的暖光。
3. **季节 tint 暖窗压制**：日落（c 0.40→0.52）/破晓（c 0.90→1.0）窗口内，章节/季节 skyTint 混入强度额外 ×(1−0.55·warmK)（平滑渐变防色跳）——否则春季 `#87ceeb` tint 会把日落拉回蓝灰，暖调永远出不来。
4. 白昼 `#87ceeb` 与深夜 `#0b1026` **不动**：春基线的"正常 MC 天"是后续章节崩坏感的对照组（demo-vision §一）；深夜是恐惧基线。

| 时段（c） | 天空 | 依据 |
|---|---|---|
| 白昼 <0.42 | `#87ceeb` | 春基线（不动） |
| 日落 0.42→0.5 | → `#e29a68` | 赭石琥珀（D-1 新值） |
| 入夜 0.5→0.58 | `#e29a68` → `#0b1026` | 过渡 |
| 深夜 0.58→0.92 | `#0b1026` | 恐惧基线（不动） |
| 破晓 0.92→1.0 | `#0b1026` →（55% 处）`#e8c79e` → `#87ceeb` | 绢本淡赭停点（D-1 新增） |

> ⚠️ 本节更新 art-bible §2.3 固化值（原日落 `#ff9a5a`、无破晓停点）；art-bible 已加指引注释，以本文为准。

## 4. 边缘情况

| # | 情况 | 处理 |
|---|---|---|
| E1 | chunk 跨界一致性 | LUT 纯函数 of (cx,cz,seed)，两侧 chunk 对同列算出同带；重载/存档后颜色不变（世界数据零增量） |
| E2 | 玩家放置的草/叶 | 按所在列带变色（自然融入，无需特判） |
| E3 | 章节迁移 blockReplace（毁田草→土） | 土不变色，裸土圈语义保留（art-bible §3"地表叙事"） |
| E4 | 挖掘/破坏粒子 | 用基准瓦片平均色（枯黄带挖草飞出嫩绿粒子）——P2 待接 BAND_PALETTE（见 §6） |
| E5 | hotbar/手持缩略图 | 恒基准色（草方块不可获得、树叶无掉落，实际不可见） |
| E6 | 旧调用兼容 | `buildChunkGeometry(..., bands?)` 缺省回退基准瓦片（tools/test-mc2b 等直调不炸） |
| E7 | 性能 | 每 chunk 新增 ~1.5k 次噪声采样（生成期一次）+ 6 张 16×16 变体瓦片（atlas 一次性绘制）；运行时 mesher 仅查 Uint8Array |
