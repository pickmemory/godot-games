## 0. 一句话与设计目标

**一句话**：你是一名带着「改写/因果系统」的穿越者，坠入三国·赤壁之战——你不是来见证历史的，你是来**拨动**它的；每一次抉择都被系统丈量成"历史偏差"，并决定你在下一个历史节点能改写多少。

**设计目标**：用一个完整的赤壁垂直切片（1 朝代 + Loop A 闭环可玩）证明——"以系统之力改写历史"这件事**好玩且成立**。

## 1. 术语词汇表（全文 + Phase 2 继承）

为避免跨文档术语漂移，本文档定义如下术语，Phase 2 各 GDD 应沿用同一语义：

| 术语 | 定义 | 单位/类型 |
|---|---|---|
| **历史基准线（Baseline Timeline）** | 史实既定走向，系统判定的"原线"。 | 世界状态 |
| **历史偏差 Δ（Deviation）** | 玩家行为导致的关键变量偏离基准线的加权程度；`Δ=0` 表示完全贴合史实，越大越偏。 | 无量纲分（分） |
| **因果点 CP（Causality Points）** | 由改写行为产出的偏差兑换而来的成长货币。 | 点 |
| **改写节点（Rewrite Node）** | 主线任务上、玩家可介入抉择的关键历史时刻（如借东风）。 | 关卡/事件 |
| **关键变量 v_i（Key Variable）** | 决定一个节点历史走向的离散状态量（如"风向"、"连舟程度"）。 | 枚举/数值 |
| **历史线（Timeline Branch）** | 一组关键变量取值共同决定的世界状态分支。 | 世界状态 |
| **因果链（Causal Link）** | 上一节点关键变量向下一节点的传递/依赖关系。 | 关系 |
| **系统（The System）** | 穿越者携带的"改写/因果系统"，作为面板、旁白、奖励发放者。 | 机制集合体 |

> ⚠️ 本表为概念级定义。`Δ` 与 `CP` 的精确公式、变量集合与权重量表在 **P2-2 改写/因果引擎 GDD** 落地；本文档仅给**示意公式**并标明变量与单位，不作为数值定稿。

## 2. 设计支柱（Design Pillars）

三条支柱从项目基线提炼，**每条都可在 MDA（第 3 节）与核心循环（第 5 节）中被追溯到**，避免漂移。

### 支柱 ① 改写即玩法——"历史是你的可玩材料"
> 改写不是过场动画里的一段字幕，而是玩家**亲手操作的核心动词**。系统的价值不是"播给你看"，而是"让你改，并告诉你改动了多少"。

- **可追溯性**：支撑 Loop A 的"改写"环节；对应 Mechanics 中的"改写动词"与"历史偏差计算"。
- **反例（漂移红线）**：若改写变成纯 QTE 或纯选择支、没有可丈量的偏差反馈，则此支柱崩塌。

### 支柱 ② 系统流的掌控感 × 正剧底色——"穿越者孤独，但你看得见天平"
> 玩家获得的是**可读的掌控感**：系统面板把赤壁这盘乱棋翻译成可读的变量与偏差。但世界本身是正剧的——血是热的，计谋是真的，NPC 不是数据。

- **可追溯性**：支撑"反馈"环节与"成长"环节；对应自我决定论的**胜任**（Competence）诉求。
- **反例（漂移红线）**：若系统吐槽盖过正剧沉浸（变成搞笑游戏），或世界过度游戏化（NPC 沦为数值载体），则此支柱崩塌。

### 支柱 ③ 赤壁是可丈量的沙盘——"开放世界即历史棋局"
> 赤壁不是问号收集清单，而是一盘**可读、可联动、可因果联动**的历史棋局：风向、连舟、粮草、人心是互相咬合的系统，玩家探索就是读懂这盘棋。

- **可追溯性**：支撑"探索"环节；对应 Aesthetics 中的 **Discovery / Challenge**，以及因果链机制。
- **反例（漂移红线）**：若开放世界退化为线性的任务传送门（据点之间无因果联动），则此支柱崩塌。

> 📌 **支柱→机制追溯表**（验收用）见第 8 节自检。

## 3. MDA 三层分析

> MDA = Mechanics（机制，规则与数据）/ Dynamics（动态，玩家与机制交互涌现的行为）/ Aesthetics（美学，玩家产生的情感体验）。三层必须自洽：M 产生 D，D 产生 A。

### 3.1 Mechanics（机制层）

**核心动词集（玩家能做什么）：**

| 动词类别 | 具体动词 | 所属循环 |
|---|---|---|
| **改写动词** | 杀 / 救 / 策反 / 截断 / 伪造 / 误导 / 说服 | Loop A · 改写 |
| **系统动词** | 查看偏差 Δ、兑换 CP、升级技能树、使用系统术法 | Loop A · 反馈/成长 |
| **战斗动词** | 普攻、闪避、系统术法/技能释放 | Loop B（即时） |
| **探索动词** | 移动、对话、收集情报、潜行、结盟 | Loop A · 探索 |

**机制要素：**
- **改写节点系统**：每个节点含一组关键变量 `v_i`，玩家行为改变 `v_i` 取值。
- **历史偏差计算**：`Δ = Σ_i ( w_i · d(v_i) )`，其中 `w_i` 为变量权重（无量纲），`d(v_i)` 为该变量相对基准的偏离度。示意公式，权重量表待 P2-2 定稿。
- **因果点产出**：`CP += f(Δ, 意图匹配度)`。⚠️ **不是单纯 `Δ` 越大越好**（见第 7 节待审批项 ③）。
- **因果链**：节点 `N` 的部分 `v_i` 作为节点 `N+1` 的输入/前置条件（如"连舟程度"传入"火攻威力"）。
- **实时战斗**：俯视角轻动作，普攻 + 系统术法/技能；伤害、硬直、资源消耗为基础规则。
- **开放世界探索**：移动/交互/收集；探索获取的**情报**可解锁改写条件、降低改写难度。

### 3.2 Dynamics（动态层 —— 机制与玩家交互涌现的行为）

| 涌现行为 | 由哪些机制产生 | 设计意图 / 风险 |
|---|---|---|
| **蝴蝶效应（因果链联动）** | 关键变量跨节点传递 | 制造"我的选择有分量"的体感；风险：复杂度爆炸 → 用**有限变量集**约束。 |
| **情报→改写 的收益回路** | 探索解锁改写条件 | 让"探索"不是纯跑图，而是策略投资。 |
| **风险/回报权衡** | 策反高回报但需潜行（高被发现风险） | 制造策略张力。 |
| **主导策略风险** | 若某条改写路径稳定最优 | ⚠️ 红线：必须避免"全力改写=最优"或"躺平贴合=最优"。见第 7 节 ③。 |
| **系统人格化陪伴** | 系统作为旁白/观测者 | 在单机环境补"关系"诉求（见第 4 节）。 |

### 3.3 Aesthetics（美学层 —— 玩家得到的情感，落到具体感受，非口号）

采用 Hunicke 等人的 8 类美学体验，本作主打 **5 类 + 1 类轻量**：

| 美学 | 在本作中的具体情感落点 | 支撑支柱 |
|---|---|---|
| **Fantasy（幻想）** | "我以系统之力拨动天命"——穿越者俯瞰赤壁、一念改写战局的**天命感**。 | ① ③ |
| **Narrative（叙事）** | 历史线分叉演出带来的"原来历史还能这样"的**叙事惊奇**。 | ① |
| **Challenge（挑战）** | 两层：①改写节点的**策略解谜**（读懂因果、规划改写）；②战斗的**动作技巧**。 | ① ③ |
| **Discovery（发现）** | 探索赤壁世界发现历史细节、民间志怪奇遇、隐藏改写路径的**求知满足**。 | ③ |
| **Expression（表达）** | 不同改写塑造"属于我的三国"，玩家**自我投射**到历史走向。 | ① ② |
| *（轻量）Sensation（感官）* | litRPG 系统面板的**即时爽感反馈**（数值跳动、偏差可视化）。 | ② |

> 三层自洽性：M（改写动词 + Δ 计算）→ D（蝴蝶效应 / 权衡 / 系统陪伴）→ A（Fantasy / Narrative / Challenge），链条闭环。Aesthetics 全部落到**可指认的情感**，不停留在"史诗感"这类口号。

## 4. 玩家心理映射

采用**自我决定论（SDT）**为主框架，辅以 **Bartle 玩家类型**定位目标受众。

### 4.1 自我决定论（自主 / 胜任 / 关系）

| 诉求 | 本作如何满足 | 机制支撑 |
|---|---|---|
| **自主（Autonomy）** | 改写分支选择、开放世界自由探索顺序、结盟/策反对象自选。 | 改写节点多分支 + 开放世界 + 多改写动词。 |
| **胜任（Competence）** | **系统把赤壁翻译成可读变量 + 可丈量的 Δ**，玩家清楚自己"改了多少、为什么"；战斗技能可精通。 | Δ/CP 面板、因果链可视化、技能树。 |
| **关系（Relatedness）** | 与历史人物（诸葛亮/曹操/周瑜/关羽）建立**师徒/敌友/策反**关系；**系统本身人格化**为陪伴者/旁白。 | NPC 关系系统 + 系统人格化叙事。 |

> ⚠️ **已知风险**：本作为单机（PC 优先，无在线服务），SDT 的"关系"诉求天然弱于多人游戏。
> **缓解**：(a) 系统作为**有性格的观测者/旁白**承担陪伴角色；(b) NPC 关系做到足够深（师徒线、敌友转化）。详见第 7 节风险。

### 4.2 Bartle 玩家类型定位

| 类型 | 吸引度 | 说明 |
|---|---|---|
| **Achiever（成就者）** | ★★★★★（主） | 系统成长、改写成就、Δ 极限挑战直接命中。 |
| **Explorer（探索者）** | ★★★★☆（主） | 开放世界历史细节、隐藏志怪奇遇、隐藏改写路径。 |
| **Killer（杀手型）** | ★★★☆☆（次） | 实时战斗、截杀/决断历史人物。 |
| **Socializer（社交者）** | ★★☆☆☆（弱） | 单机为主；靠 NPC/系统陪伴部分满足。 |

**目标受众画像**：偏好系统流/litRPG、对历史架空有兴趣、享受"智斗 + 动作"混合体验的 PC 单机玩家（18–35 岁）。

## 5. 核心循环细化（Loop A）

> 在 AGENTS.md 既定 Loop A（任务→探索→改写→反馈）基础上，画出闭环并标注**反馈如何驱动成长**与**历史偏差**。

### 5.1 主循环（Loop A）文本图

```
        ┌─────────────────────────────────────────────────────────┐
        │                                                         ▼
   ┌─────────┐   情报/资源/关系    ┌─────────┐   满足条件触发    ┌─────────┐
   │ ① 任务  │ ─────────────────▶ │ ② 探索  │ ───────────────▶ │ ③ 改写  │
   │系统派   │  解锁改写条件/      │开放世界 │  抉择改写动词    │关键节点 │
   │改写节点 │  降低改写难度        │战斗/潜行│                  │改变 v_i │
   └─────────┘ ◀───────────────── └─────────┘                  └────┬────┘
        ▲   ▲ 回面板升级后更强                                         │
        │   │ 的改写能力(因果点→技能/兑换)                              │ 计算 Δ
        │   │                                                          ▼
        │   └─────────────────────────┐                         ┌─────────┐
        │                             │                         │ ④ 反馈  │
        │                             └─────────────────────────│ Δ + CP  │
        │                              成长驱动 ⑤                │+解锁+   │
        │                                                         │历史线分叉│
        │                                                         └────┬────┘
        │                                                              │
        └──────────────── 因果链：本节点 v_i 传入下一节点 ────────────────┘
```

### 5.2 反馈如何驱动成长与历史偏差（闭环关键）

1. **反馈产出成长货币**：改写后系统计算 `Δ`，按 `CP += f(Δ, 意图匹配度)` 发放因果点 CP。
2. **成长反哺改写能力**：CP 在面板兑换技能树/系统术法/情报强化 → 使玩家能在下一节点改写**更难/更隐秘**的目标。
3. **历史偏差是双效数值**：`Δ` 既是**成长来源**（兑换 CP），又通过**因果链**影响**下一节点的存在性与难度**（如华容道节点是否出现，取决于借东风节点是否让曹操大败）。
4. **历史线分叉演出**：每次重大 Δ 触发一段"历史线分叉"可视化（时间轴分叉图 + 系统旁白），把抽象数值**翻译成叙事惊奇**——这是 Loop A 的情感峰值。

### 5.3 次循环（Loop B · 即时反馈）
Loop A 是分钟级的主循环；战斗/遭遇内还有一个**秒级**的次循环：
`遭遇 → 战斗/潜行/对话 → 即时反馈（伤害/资源/关系变化）→ 继续探索`
Loop B 为 Loop A 的"探索/改写"提供动作乐趣与微观风险，**不直接产出 Δ**，但影响改写前的状态（如被发现则改写难度上升）。

### 5.4 防主导策略
⚠️ 循环设计的核心红线：**禁止出现"全力改写 = 永远最优"或"完全躺平贴合史实 = 最优"**。
- 倾向方向（待主创审批，见 7.③）：奖励**有意图的精妙改写**（`意图匹配度` 高 + `Δ` 适度），而非盲目制造最大偏差。
- 倾斜：贴史实太死（`Δ≈0`）也应有基础 CP 但成长缓慢，倒逼玩家主动改写。

## 6. 赤壁改写节点示例 ×3

> 三个节点**互锁成因果链**，可直接喂给 P2-2 改写/因果引擎 GDD。每节点含：原始历史走向 / 介入动词 / 改写分支 / 历史偏差计算与反馈。

### 6.1 节点 N1 · 连环计（火攻的火药桶）

- **时序**：赤壁战前 · 案略阶段（最先发生）。
- **原始历史走向（基准线）**：庞统诈降曹操，献"铁索连舟"之计；曹操采纳，战船以铁索相连以求稳。**后果**：连舟使火攻可一焚俱焚，为联军火攻创造关键条件。
- **关键变量 `v_i`**：
  - `连舟程度 v_boat` ∈ {未连, 半连, 全连}，基准 = 全连。
  - `庞统存活 v_pang` ∈ {生, 死}，基准 = 生。
- **玩家可介入的动词**：揭穿（向曹操告密）/ 助力（帮庞统把连舟方案做得更"完美"）/ 截杀（杀庞统）/ 伪造（献一个"看似更优、实则有破绽"的连舟法）/ 潜行破坏（半夜解铁索）。
- **改写分支（示例）**：

| 分支 | 关键变量结果 | 相对基准的 Δ（示意） | 历史线走向 | 对下游节点影响 |
|---|---|---|---|---|
| A·原线 | `v_boat=全连, v_pang=生` | Δ≈0 | 火攻条件满足，曹军大败（基准） | → N2 火攻满威力 |
| B·揭穿 | `v_boat=未连, v_pang=生` | Δ_B ≈ +40 | 曹操不连舟，火攻威力锐减 | → N2 火攻威力大幅下降 |
| C·截杀庞统 | `v_boat=曹操自决, v_pang=死` | Δ_C ≈ +25 | 连环计无人献，曹操自行决策（结果不定） | → N2 视曹操决策而定 |
| D·伪造破绽连舟 | `v_boat=半连(有破绽), v_pang=生` | Δ_D ≈ +15 | 连舟看似成但有结构破绽，火攻可触发连锁断裂 | → N2 火攻有额外"连锁"演出 |

- **历史偏差计算与反馈**：
  - `Δ_N1 = w_boat·d(v_boat) + w_pang·d(v_pang)`；示意权重 `w_boat=0.7, w_pang=0.3`。
  - 反馈：`CP += f(Δ_N1, 意图匹配度)`；播历史线分叉演出；`v_boat` **作为因果链变量传入 N2**（火攻威力）。

### 6.2 节点 N2 · 借东风（火攻的扳机）

- **时序**：赤壁战前 · 临战阶段（承接 N1）。
- **原始历史走向（基准线）**：周瑜欲火攻却缺东南风；诸葛亮登七星坛"借"风，东南风起，火攻得以实施，曹军大败。
- **关键变量 `v_i`**：
  - `风向 v_wind` ∈ {东南, 无, 西北}，基准 = 东南。
  - `坛状态 v_altar` ∈ {完好, 毁}，基准 = 完好。
  - `诸葛亮存活 v_kong` ∈ {生, 死}，基准 = 生。
  - （输入）`v_boat`：来自 N1。
- **玩家可介入的动词**：破坏（砸坛 / 截走祭风法器）/ 截断（阻止诸葛亮上山）/ 策反（收买坛上道士）/ 伪造（假报风向情报）/ 对话（说服/威胁诸葛亮）/ **玩家自借**（穿越者用自身系统术法"借"风）。
- **改写分支（示例）**：

| 分支 | 关键变量结果 | 相对基准的 Δ（示意） | 历史线走向 | 对下游节点影响 |
|---|---|---|---|---|
| A·原线 | `v_wind=东南, v_altar=完好` | Δ≈0 | 火攻成功，曹军大败（基准） | → N3 华容道**出现** |
| B·风借失败 | `v_wind=无/西北` | Δ_B ≈ +50 | 火攻失效/反烧联军，赤壁成僵局 | → N3 华容道**消失**（曹操未败走），系统派**替代节点** |
| C·玩家自借 | `v_wind=东南(玩家之劳)` | Δ_C ≈ +30 | 火攻成但功劳/因果归于玩家，触发系统特殊旁白 | → N3 出现 + 与诸葛亮关系变化 |

- **历史偏差计算与反馈**：
  - `Δ_N2 = w_wind·d(v_wind) + w_altar·d(v_altar) + w_kong·d(v_kong)`；示意权重 `w_wind=0.6, w_altar=0.2, w_kong=0.2`。
  - **因果链体现**：N2 的火攻威力 = `g(v_wind, v_boat)`（风 + 连舟共同决定）——展示**跨节点联动**。
  - 反馈：`CP += f(Δ_N2, 意图匹配度)`；重大分支（B/C）触发长段历史线分叉演出；`v_wind` 间接决定 N3 **是否存在**。

### 6.3 节点 N3 · 华容道（败局之后）

- **时序**：赤壁战后 · 追击阶段（承接 N2）。
- **前置存在性依赖**：⚠️ 本节点**存在性依赖** N2——**仅当 N2 火攻成功、曹操大败**，N3 才存在（基准情况）。若 N2 风借失败（曹操未败），则 N3 不存在，系统改派**替代节点**（如"曹操乘胜追击——反向节点"）。这是因果链的**存在级联动**，是本作高概念卖点之一。
- **原始历史走向（基准线）**：曹操赤壁大败，败走华容道；关羽奉命埋伏，念旧情义释曹操。曹操存活 → 三国鼎立格局奠定。
- **关键变量 `v_i`**：
  - `曹操结局 v_cao` ∈ {生(义释), 死}, 基准 = 生。
  - `关羽埋伏 v_guan` ∈ {到位, 不到位, 被策反}, 基准 = 到位。
- **玩家可介入的动词**：截杀（亲自/指挥联军杀曹操）/ 放行（默许义释）/ 策反关羽（让他不放）/ 误导（引曹操走另一条道）/ 救援（帮曹操脱困，换取与魏方关系）。
- **改写分支（示例）**：

| 分支 | 关键变量结果 | 相对基准的 Δ（示意） | 历史线走向 | 系统反应 |
|---|---|---|---|---|
| A·原线 | `v_cao=生, v_guan=到位` | Δ≈0 | 义释曹操，三国鼎立（基准） | 普通 CP，温和旁白 |
| B·截杀曹操 | `v_cao=死` | Δ_B ≈ +90（重大） | 曹操死，魏国动荡，历史剧变 | **重大偏差警告** + 高额 CP + 高风险（系统提示"世界线剧烈震荡"） |
| C·策反关羽不放 | `v_cao=死, v_guan=被策反` | Δ_C ≈ +80 | 曹操死，但破坏与关羽/蜀方关系 | 高 CP + 关系惩罚 |

- **历史偏差计算与反馈**：
  - `Δ_N3 = w_cao·d(v_cao) + w_guan·d(v_guan)`；示意权重 `w_cao=0.8, w_guan=0.2`。
  - **重大偏差机制**：当 `Δ_N3` 超过阈值 `Δ_critical`（示意 +80），触发**世界线震荡**演出 + 额外 CP 但伴随风险（如系统"过载"惩罚、后续节点难度激增）——以此**抑制无脑制造最大偏差**，呼应第 5.4 节防主导策略。
  - 反馈：CP + 历史线分叉演出 + 与魏/蜀/吴三方关系重塑。

> 📌 三节点联动小结：`v_boat`(N1) ──┐
> 　　　　　　　　　　　　　　　　├─▶ 火攻威力 ──▶ 曹操是否大败 ──▶ N3 是否存在
> 　　　　　　　　　　　`v_wind`(N2)┘
> 这条因果链是 P2-2 改写/因果引擎的**最小可工作样例（MWP）**，建议直接据此设计数据结构。

## 7. 范围分层（MVP / 目标 / 愿景）

> 严格区分"垂直切片必须做"与"愿景期"，不摊薄焦点。与 `project-charter.md`「范围（垂直切片，严守）」一致。

### 7.1 MVP（垂直切片最小集 —— 证明 Loop A 成立）

- **1 个改写节点完整闭环**：建议 **N2 借东风**（最具辨识度、单节点可独立验证 Loop A）。
- **玩家能力最小集**：可移动 + 战斗（普攻 + **1 个系统术法**）+ 潜行/对话最小集。
- **系统面板最小集**：显示 `Δ` + 显示 `CP` + **1 个技能树节点可兑换**。
- **世界最小集**：1 张赤壁小区域 TileMap + ≤5 个 NPC + 1 处改写场所（七星坛）。
- **主线任务派发**：1 条（系统派 N2）。
- **MVP 验收问句**："玩家能不能在一局里跑完 任务→探索→改写→反馈→成长 一次？"

### 7.2 目标（垂直切片完整态 —— 证明"好玩"且系统可支撑）

- **3 个改写节点串成赤壁主线**：N1 连环计 / N2 借东风 / N3 华容道，含**因果链联动**与**N3 存在性依赖**。
- **战斗完整集**：普攻 + 多个系统术法/技能 + 闪避/硬直。
- **面板成长完整集**：技能树多分支 + CP 兑换 + 情报强化。
- **世界完整集**：赤壁主区域 + 关键据点（夏口 / 乌林 / 赤壁主战场 / 华容道）。
- **机制完整集**：结盟 / 策反 / 潜行 / 截断 / 伪造 等多改写动词；NPC 关系系统（至少 4 名核心人物）。
- **目标验收问句**："玩家改写一处后，会不会忍不住想'再来一局换种改法'？"

### 7.3 愿景（多朝代扩展铺路 —— **明确不在本切片**）

> 以下仅作为"架构不挡路"的铺路提示，**本切片不实现**，避免焦点摊薄。

- 朝代热切换：朝代 = TileSet + 遭遇表 + BGM 的组合（与 AGENTS.md Godot 约定一致）。
- 历史偏差跨朝代累积（一个穿越者的"偏差总账"）。
- 更多改写动词、阵营系统、更大规模 NPC 网络。
- 移动端适配、Live Ops / 在线服务（明确后期）。

### 7.4 明确"不做"清单（防范围蔓延）

- ❌ 商城氪金 / 签到日常 / 在线服务（后期/Live Ops）。
- ❌ 多朝代地图（愿景期）。
- ❌ 本切片不做"消失节点"以外的复杂因果网；因果链**限定在 3 节点最小链**。
- ❌ 程序化生成历史线；所有历史线分叉为**手工设计 + 数据驱动**。

## 9. 待主创审批项（发现基线张力，不擅自定稿）

> 以下 4 项是概念孵化中浮现的、需要主创（贺弈）拍板的设计方向。本文档**不擅自定稿**，给出倾向 + 理由供决策。

1. **【系统人格基调】litRPG 元幽默 vs 正剧沉浸的边界**
   - 张力：系统吐槽过多会破坏赤壁正剧；过少则失 litRPG 味。
   - 倾向：系统以"**冷峻的第三方观测者/记录员**"人格出现，元幽默**仅限于系统注释/UI 弹窗**，绝不渗入 NPC 台词与世界叙事。
   - 待定：系统人格的具体语气（是冰冷数据流，还是带点毒舌的"记录员"？）。

2. **【奇幻来源体系】"民间志怪奇幻"的奇幻度边界（防纯修仙）**
   - 张力：借东风、术士、志怪奇遇需要"奇幻"支撑，但基线明确"非纯修仙"。
   - 倾向：区分**两套奇幻来源**——(a) 玩家系统术法 = 穿越者带来的能力（科学/系统侧）；(b) 民间术士/志怪 = 真实存在的本土超自然（民间志怪侧）。玩家**不修炼本土法术**，保持"外来者"身份。
   - 待定：本土奇幻的上限（能否呼风唤雨，还是只到"兆头/小术"级别？）。

3. **【奖励曲线方向】Δ 与 CP 的关系——鼓励"大改"还是"精妙微调"？**
   - 张力：这直接决定主导策略（全力改写 vs 躺平贴合）。
   - 倾向：奖励**有意图的精妙改写**——`CP = f(Δ, 意图匹配度)`，并设 `Δ_critical` 重大偏差震荡惩罚（见 6.3）。即"乱改不奖励，懂因果地改才奖励"。
   - 待定：`意图匹配度` 如何被系统判定（玩家输入如何表达"意图"？）。

4. **【MVP 因果链范围】"消失节点"是否进 MVP？**
   - 张力：N3 存在性依赖是高概念卖点，但增加系统复杂度。
   - 倾向：**MVP 只做存在节点（N2 借东风）**；"消失节点/替代节点"逻辑放到**目标态（7.2）**实现。
   - 待定：MVP 是否值得为"消失节点"提前做架构预留？（建议：架构预留，实现延后。）

## 10. 已知风险与取舍

1. **单机关系诉求弱**（SDT Relatedness）→ 缓解：系统人格化 + 深度 NPC 关系线（见 4.1、待审批 1）。
2. **因果链复杂度增长** → 取舍：本切片**限定 3 节点最小链**，超出范围的因果网列为愿景（见 7.4）。
3. **主导策略风险** → 由 `意图匹配度` + `Δ_critical` 双保险抑制（见 5.4、待审批 3）。
4. **历史考据 vs 游戏性** → 取舍：以"民间志怪架空"为盾，允许为游戏性偏离正史，但**核心人物动机**保持可识别（如曹操多疑、关羽重义）。
