## 1. 风格参照与视觉总纲

### 1.1 一句话风格

> **汉代民间的物质世界**，用 **MC 体素语法**搭建，用**绢本长卷的光与雾**观看。

三个不可妥协的锚点：

| 锚点 | 含义 | 反例（禁止） |
|---|---|---|
| **土的** | 主色域是夯土、陶瓦、麻衣、生铁——低饱和大地色；鲜艳色只允许出现在「历史闯入」时刻（黄巾的黄、官军赤帜、洛阳的火） | 鲜艳卡通糖果色（Kenney 默认调需校准，见 §8.3） |
| **旧的** | 一切人工物有使用痕迹：瓦有苔、木有裂纹、布有毛边；世界在编年里被消耗 | 崭新塑料感、均匀无噪贴图 |
| **会烧掉的** | 建筑材质按「可焚性」分层（茅<木<夯土<砖石）；第二章洛阳大火要用材质语言讲「繁华与灰烬」 | 不可摧毁的宏伟感、纪念碑式建筑 |

### 1.2 风格参照板

- **体素语法**：Minecraft（手感基准，但**不做像素级复刻**，DMCA 红线）；Kenney Voxel Pack 的干净几何 + 我们的调色。
- **汉代物质**：汉代陶楼/画像砖（四川出土明器）的木构比例；板瓦、夯土版筑、篱笆院落的村落肌理。
- **长卷光感**：《千里江山图》的青绿只做 UI 章节卡的点缀色；世界内是《流民图》式的灰黄——**平民看天下，天是土色的**。
- **参照红线**：不参照任何三国游戏（无双/全战/卧龙）的视觉语言——它们是英雄视角，我们是平民视角。

### 1.3 视觉总纲如何服务三层信条

| 信条层 | 美术手段 |
|---|---|
| 先给恐惧 | 夜色 `#0b1026` 压到准星只看清 3 格；行尸是「人形的破布」而非怪物设计；受击红晕用深血 `#8c0a0a` |
| 再给天梯 | 工具/建材随天梯升级**变亮变规整**（泥土暗浊 → 木板温黄 → 砖石冷灰），玩家从色温就能读出自己的进度 |
| 最后给沙盒 | 建成物的「汉风辨识度」奖励：瓦顶、夯土墙、篱笆院——玩家自己拼出画像砖里的村落 |

## 3. 构图与环境视觉

- **雾是构图工具**：视距即信息权。平民看不见大军，只看得见「雾里多出来的东西」——第一章秋季 fogFar 110、`autumn-smoke` 压 95，皆是把「看不远」物理化（已落地）。新章节雾值以 §2.4 为准。
- **框景**：门（`DOOR_*` 上半棂格窗）、木窗（`WINDOW`）是天然画框——NPC 立绘对话、事件 notify 应优先发生在玩家透过自家的窗看到的时刻（演出调度属 MC-5b+，此处只立原则）。
- **烟柱**：远处事件的视觉残留（黄巾起事、洛阳大火）。占位方案=远处垂直黑色粒子柱（粒子里复用 `tileColors` 机制）；正式方案待粒子系统预算（§9.3）。
- **季节读法**：现有 skyTint+fogFar 已够 P0；冬季草地/树叶褪色（`grassTint`/`leavesTint`）已在 mc3-chapter1 §3.2 标记【需程基岩确认】，美术目标值：冬草 `#9aa884`、冬叶 `#6a7a54`（不落雪——冀州冬以枯黄为主，雪留作事件彩蛋）。
- **地表叙事**：`blockReplace`（官军毁田）留下的「裸土圈」是构图元素而非缺陷——环形裸土+中央残垄，正是「大军过处」的俯视画面。禁止用装饰方块「修复」它。

### 4.3 关键变体的注册表定义（程基岩可直接抄）

```js
// TILE 追加（textures.js PAINTERS 同步追加绘制器）——MC-5b 已落地，实际瓦片号见上表
RAMMED_EARTH: 26, HAN_TILE: 27, THATCH: 28,
CHARRED_WOOD: 29, ASH: 30,

// BLOCK_DEFS 追加（硬度按 mining.js 天梯：土系<石系）
{ name: '夯土', solid: true, transparent: false, hardness: 0.9, tiles: { top: TILE.RAMMED_EARTH, side: TILE.RAMMED_EARTH, bottom: TILE.DIRT } },
// 夯土：版筑层理（水平条纹），汉代墙体的「正式」建材——比泥土耐看，比汉砖便宜
{ name: '汉瓦', solid: true, transparent: false, hardness: 1.8, tool: 'pickaxe', minTier: 1,
  tiles: { top: TILE.HAN_TILE, side: TILE.HAN_TILE, bottom: TILE.PLANK } },
// 汉瓦：满格简化（不做坡屋顶几何）；青灰陶色 #5a6360，顶面叠瓦垄纹
{ name: '焦木', solid: true, transparent: false, hardness: 0.7, drop: 0, tiles: { top: TILE.CHARRED_WOOD, side: TILE.CHARRED_WOOD, bottom: TILE.CHARRED_WOOD } },
// 焦木：黑碳纹 + 余烬橙点 #d4622a；drop:0——烧掉的就是没了（焚洛阳的世界状态残留）
{ name: '灰烬层', solid: true, transparent: false, hardness: 0.2, tiles: { top: TILE.ASH, side: TILE.ASH, bottom: TILE.ASH }, collision: [[0,0,0,1,0.4,1]] },
// 灰烬：半格高软层，踩上去扬灰粒子（粒子色 #9a938a）
{ name: '茅草顶', solid: true, transparent: false, hardness: 0.4, tiles: { top: TILE.THATCH, side: TILE.THATCH, bottom: TILE.PLANK } },
// 茅草：干黄 #c9b06a 束纹；可焚性最高的「穷建材」——材质语言讲述阶级
{ name: '黄巾旗帜', solid: false, transparent: true, cross: true, selectable: true, hardness: 0.05, tiles: { top: TILE.BANNER_YT, side: TILE.BANNER_YT, bottom: TILE.BANNER_YT } },
// 黄巾旗：十字面片（同作物管线），麻布黄 #e3c14f 破边 + 墨字符号；solid:false 可穿行
```

`shape`/朝向（门/楼梯样式）暂不引入旗帜的 2 格高版本——P0 用 1 格 cross；旗帜双格高+摆动动画（§7）留 P2。

### 4.4 贴图规格（16×16 像素级，PAINTERS 或替换贴图都遵守）

- **夯土**：基色 `#b39b6f`，每 4 px 一条水平版筑暗线（`#9c8358`），噪点 ±10%；**无垂直结构**（版筑是水平工艺）。
- **汉瓦**：基色 `#5a6360`，横向瓦垄（每 4 px 一垄，垄脊亮 `#6f7a72`、垄谷暗 `#4a514e`），随机 2~3 处苔斑（`#7a8a6a`）。
- **焦木**：基色 `#26211c`，纵向裂纹露出内层 `#3a322a`，2~3 点余烬 `#d4622a`（半透明 0.6）。
- **灰烬**：基色 `#9a938a`，大噪点 ±14%，2 处未燃尽黑斑。
- **茅草**：基色 `#c9b06a`，竖向束纹（每 3 px 一束，束尖下垂 1 px），束根暗 `#a58f52`。
- **黄巾旗**：透明底；旗面 `#e3c14f` 占 12×10 px，右缘毛边（随机豁 2 px），中央墨痕 `#2b2620` 一笔（抽象「苍」字意，**不画可读汉字**——16×16 画不清，画了反而假）。
- 样张（mmx 生成的风格参考，非入库贴图）：`web/assets/art/blocks/rammed-earth-sample.jpg` / `han-tile-sample.jpg` / `yellow-banner-sample.jpg`。

### 4.5 边缘情况

- **E-变体①**：`blockReplace`（官军毁田）`from:1 to:2` 只认草→土；190 焚洛阳用多条 blockReplace 效果链接实现分材质焚烧（茅草/草木→灰烬、木板/原木/木窗→焦木、树叶→空气，夯土/汉瓦不动），已由 MC-5b 设计定案（见 mc5-chapter2.md §3.4）。
- **E-变体②**：灰烬层半格 collision 会产生玩家可站上去的视觉/碰撞不一致（0.4 高 vs 满格渲染）——**渲染也要非满格**（mesher 需支持半格高面片，同楼梯已有先例）【需程基岩确认：半格渲染复用 stairs 管线】。
- **E-变体③**：旗帜 cross 面片与作物共用 alphaTest 材质——破边毛边像素必须 α≥1 或 =0（禁半透明渐变），否则 alphaTest 阈值会裁出锯齿洞。

## 5. UI 书法风规范

### 5.1 总则

UI = **绢上墨字**。世界是第一人称的、拥挤的；UI 是卷轴的、留白的。UI 永远不遮挡画面中心（准星工作区），沿画框边缘分布（现有布局已符合，保持）。

### 5.2 字体层级（四级 + 一特例）

| 层级 | 用途 | 字体栈（CSS） | 字号/字距 | 颜色 |
|---|---|---|---|---|
| L1 题签 | 章节卡、开场/结尾演出（#csTitle）、死亡界面 | `"Kaiti SC","STKaiti","KaiTi","楷体","Microsoft YaHei",sans-serif` | ≥36px / letter-spacing 12px | 墨 `#2b2620` 于绢底，或绢金 `#e8d9b0` 于黑底 |
| L2 旁白 | cutscene 行、notify | 同上（楷体） | 16~18px / 3px | `#e8d9b0`（黑底） |
| L3 标题 | 面板标题（#craft h2、#dName）、#blockName | 同上 | 17~20px / 3~8px | `#e8d9b0` |
| L4 正文 | 对话正文、配方、HUD 小字 | `"Songti SC","STSong","SimSun","宋体","Microsoft YaHei",sans-serif` | 12~14px / 1~2px | `#fff` 或 `rgba(255,255,255,.6)` |
| 特例 数字/键位 | FPS、槽位号、计数 | `Consolas, monospace`（现状保留） | 10~12px | 现状保留 |

**落地方式（P0，一处 CSS 改动）**：`web/index.html` 全局字体栈由 `"Microsoft YaHei"` 改为 L2 楷体栈，L4 局部覆盖宋体栈。零构建、无字体文件引入；楷体是 Win/macOS 系统字体（发布期 Electron 壳内嵌开源楷体 .ttf【发布前确认：霞鹜文楷 OFL 许可合规，届时登记 CREDITS】）。

### 5.3 组件规范

- **章节卡（cutscene 题签）**：黑底 `rgba(8,10,20,.95)` → 墨字 + 右下角朱印（8×8px 印章红 `#b03a2e`，内容为「長卷」篆意方块，不刻可读字）。现状 cutscene.js 结构已支撑，仅换字体栈+加印章元素。
- **旁白行**：逐行淡入（cutscene.js 已实现），行间距 1.8em，行首不加项目符；引号内的演出文案（mc3-chapter1 §5）全用 L2。
- **notify（HUD 长旁白）**：保持现有位置（hotbar 上方）与 `#ffe9a8` 色；≥2 行时自动上移避让 hearts。notify 是「陈叟在你耳边说话」——不加大字、不加边框。
- **hotbar**：现有 48px 槽位 + `#ffd76a` 选中态符合规范，保持；**唯一改动建议**：槽位边框由白转绢 `rgba(232,217,176,.4)`（P2 微调，可不做）。
- **合成面板/对话面板**：绢底暗棕 `rgba(22,18,12,.94)` + 金边 `rgba(255,215,106,.35)`（现状即规范，固化）；面板标题用 L1 楷体。
- **题签文字红线**：**题签/旁白文字一律 DOM 真字渲染，禁止 mmx 生成带字贴图**——实测（`web/assets/art/ui/title-calligraphy-sample.jpg`）AI 书法会写错字（「三国长卷」生成成「寄离中玖」）并擅自加英文。mmx 只出**无字材质**：绢底纹理、印章、墨点装饰。

### 5.4 可访问性

- 正文对比度 ≥4.5:1（`#fff`/`rgba(255,255,255,.6)` 于 `.94` 黑底，达标）；楷体笔画细，L1/L2 禁用 <16px。
- 所有 UI 文案随存档语言走中文简体；不预留多语言（超出范围，主创另定）。

1. 源：Quaternius「Universal Animation Library / Locomotion」人形（CC0），选**无装备、站姿**基础模型。
2. 比例校正：GLB 原模通常 1.7~2.0m 直接可用；导出时统一 **Y-up、脚底=原点、身高缩放至 1.85**（npc.js 按 `model.height` 计算碰撞与名牌锚点，已落地）。
3. 换装：Quaternius 模型贴图重绘为民系配色（§6.2）——用 64×64 调色板重映射（其贴图为分区平铺，直接替换色值即可保留 shading）。
4. 动画：保留 Idle/Walk 两组；对接 npc.js 现有 approach/wander 状态（AnimationMixer 管线已预留）。
5. 登记引入来源 URL + CC0 到 `web/assets/CREDITS.md`（§8.5 流程）。
6. 历史人物（如 MC-5b+ 董卓等）建模原则沿用 mc3-chapter1 §2.3：**章节内无戏份的历史人物不建模**。

### 6.4 边缘情况

- **E-角色①**：行尸 1.9 高 vs 玩家 1.8——碰撞均按各自 AABB（现状正确）；但低矮通道（1 格高）两者都过不去，符合预期。
- **E-角色②**：GLB 加载失败（断网/路径错）→ npc.js 需保持 procedural 模型兜底（现状已有 type 分支，落地时验证 fallback 分支可用）。
- **E-角色③**：名牌（CanvasTexture）在楷体栈缺失机器上退化为黑体——可接受（L4 层级）。

## 7. 动画原则

- **幅度小**：体素世界的动画是「块的位移」不是「骨骼的弧线」。行走摆幅 ≤15°，待机呼吸上下 1~2px（0.05 格）。
- **性能红线**：动画只动 Object3D 变换（position/rotation），不动材质；每 NPC ≤2 个同时动画通道。
- **叙事动画白名单**（当前引擎范围）：NPC approach 转向（已落地）、行尸受击顿帧（mob.js 现有）、作物生长（贴图阶段切换，已落地）、旗帜摆动（P2：顶点 sin 偏移或 UV 滚动，待预算）。
- **禁止**：布料模拟、骨骼 IK、表情系统——超出体素语法的写实动画会撕破风格。
- 手持工具摆动（helditem.js 现有）幅度保持：挖掘循环 8° 摆动是「手感」的一部分，美术不压缩。

2. 选 16×16 PNG → 映射到本圣经 §2.1 色板：HSL 校色（亮度差 ≤8%、色相差 ≤10°），Kenney 偏亮的默认调整体压暗 5~10%。
3. **atlas 布局不变**：`TILES_PER_ROW=4`、瓦片序号即 `TILE` 表值；替换 = 只改 `textures.js` 的 PAINTERS 为 drawImage 切片（该文件头部已有 TODO 注释预留此方案）。

### 8.5 CREDITS 登记流程（强制，缺登记者 review 拒合并）

3. review 时校验 CREDITS 与 `web/assets/` 实际内容一一对应（孤儿文件=FAIL）。
