## 3. 长描述（页面正文，中文）

> 184 年，天下大疫。你是一个没有名字的流民，逃到钜鹿郊野的一座小村。
>
> 白天，你挖土、伐木、锻石镐，版筑夯土墙，给自己搭一间能过夜的屋。粟米按季节生长，火把在夜里烧短一截。日子有手感和重量——这是沙盒给你的。
>
> 然后历史来了。太平道的传道人进村，黄巾起事，官军过境，烽烟一年一年烧近。你改变不了它：不改写历史，是本作唯一的规矩。你只是在场，并且要活下来——这是编年史给你的。
>
> **《三国长卷》Demo 包含**
> - 两章真实编年：184·黄巾 → 190·讨董（迁都焚洛阳），世界状态随史实迁移
> - MC 骨架手感：挖掘天梯（木→石→铁）、第一夜恐惧、农耕、版筑建造、房屋判定招徕流民
> - 中式生存细节：十二时辰日晷读时、火把篝火点光、粟米农耕、昼夜四态与季节
> - 开场长镜头 + 章节题签 + 全程中文旁白
>
> 这是一份垂直 Demo：两章之外的长卷（官渡、赤壁……）在制作路上。欢迎把你的第一夜讲给我们听。
